# example-locker

A Midnight example demonstrating zero-knowledge private state through a locker rental system.

A 4-digit combination is set when renting a locker — only its hash is stored on-chain. Opening the locker produces a ZK proof that the combination matches without revealing the digits.

## Prerequisites

- Node.js >= 20
- [Compact toolchain](https://docs.midnight.network/compact/compilation-and-tooling/compiler-usage) (`compact` CLI, version 0.30.0)
- Docker — for local devnet or proof server

See [docs.midnight.network/relnotes/support-matrix](https://docs.midnight.network/relnotes/support-matrix) for the full version matrix.

## Quick start (preprod)

```bash
# 1. Start the proof server
docker compose -f proof-server.yml up -d

# 2. Install, compile, and run
npm install
npm run compact
npm run preprod
```

Fund your wallet at [faucet.preprod.midnight.network](https://faucet.preprod.midnight.network/).

## Local devnet (standalone)

Use standalone if preprod is unavailable. It requires [midnight-local-dev](https://github.com/midnight-ntwrk/midnight-local-dev) to be running first:

```bash
# Terminal 1 — start the devnet
git clone https://github.com/midnight-ntwrk/midnight-local-dev
cd midnight-local-dev && docker compose up

# Terminal 2
npm install
npm run compact
npm run standalone
```

The genesis wallet is pre-funded — no faucet needed.

## Project structure

```
example-locker/
  contract/
    src/
      locker.compact    ← Compact smart contract
      witnesses.ts      ← Witness implementation + LockerPrivateState
      managed/          ← Generated by npm run compact (gitignored)
  locker-cli/
    src/
      config.ts         ← Network configs (standalone, preprod)
      common-types.ts   ← Type aliases for midnight-js
      api.ts            ← Contract operations + wallet setup
      cli.ts            ← Interactive CLI
      standalone.ts     ← Entry: local devnet
      preprod.ts        ← Entry: preprod
  proof-server.yml      ← Docker Compose for local proof server
  package.json
  tsconfig.json
```
